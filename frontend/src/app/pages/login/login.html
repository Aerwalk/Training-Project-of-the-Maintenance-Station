видно всё

Заявки, клиенты, автомобили и мастера — в одном интерфейсе поверх настоящей PostgreSQL. Данные не имитация: каждая карточка читается из базы СТО.

  • Жизненный цикл заявки Создание, услуги, закрытие и журнал статусов
  • Реальные данные REST API работает через HikariCP и хранимые функции
  • Роли и доступ Администратор, менеджер, мастер и клиент
