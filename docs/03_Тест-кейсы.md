# Тест-кейсы

**Документ:** набор тест-кейсов (задания 5–6)  
**Состав:** 20 функциональных кейсов `TC-01…TC-20` (8 негативных) и 10 кейсов устойчивости `RS-01…RS-10`  
**Связанные документы:** [План тестирования](02_План_тестирования.md), [Результаты тестирования](04_Результаты_тестирования.md)

> В колонке «Статус» при проведении тестирования указывается `Пройден`, `Не пройден`, `Частично` или `Не выполнен`. В исходном наборе поле оставлено пустым; фактические результаты приведены в [04_Результаты_тестирования.md](04_Результаты_тестирования.md).

## 1. Условные обозначения

| Поле | Значение |
|---|---|
| Тип | позитивный / негативный / граничный / безопасность |
| Приоритет | критический / высокий / средний / низкий |
| Предусловия | состояние стенда и данных до выполнения |
| Шаги | последовательность действий тестировщика |
| Ожидаемый результат | наблюдаемый и проверяемый итог |

Общие предусловия для большинства кейсов: контейнер `sto-postgres` запущен (`docker compose up -d`), применены `sto.sql` и `02_seed.sql`, приложение собрано (`mvn package`).
